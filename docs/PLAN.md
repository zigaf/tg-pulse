# TGPulse — план реализации

> Рабочее название. Продукт: атрибуция и сквозная аналитика трафика Telegram-каналов.
> Цель: «лучшая копия» tgtrack.ru («Откуда Подписки») + сильнейшие фичи Prizma / Telescope / Adstat.
> Хостинг: Railway (web + bot + Postgres + Redis).

## Позиционирование

Для админов каналов, закупщиков и агентств, которые платят за трафик.
TGPulse отвечает на вопрос: **«какая связка приносит подписчиков и деньги, а какая сливает бюджет»** — в реальном времени, в красивом веб-дашборде, без Excel.

Ключевые отличия от tgtrack.ru:

| tgtrack.ru | TGPulse |
|---|---|
| Отчёты в Excel-файлах | Realtime веб-дашборд + шаринг отчёта клиенту по ссылке |
| Точность падает при >50 подписчиков/день | Атрибуция через уникальные инвайт-ссылки — точная на любых объёмах |
| Нет командных функций | Воркспейсы, роли, агентский режим, white-label отчёты |
| История кликов — 1 год | Без ограничений |
| Только подписчики | Модуль «Продажи»: ROMI по источникам (как Prizma) |
| Только RU | RU-first, архитектура готова к EN |

## Архитектура атрибуции (ядро)

**Главное техническое решение, которое убирает лимит «50 подписчиков/день»:**

1. На каждый креатив/площадку создаём **уникальную инвайт-ссылку канала** через Bot API
   (`createChatInviteLink`, бот — админ канала с правом приглашения).
2. Публичная трекинг-ссылка `go.<domain>/l/<slug>` → фиксируем клик (UTM, referer, ua) → 302 на инвайт-ссылку
   (или напрямую на пост канала — режим «посадочный пост»).
3. Событие `chat_member` (join) приходит боту **с указанием invite_link** → атрибуция подписчика к креативу
   детерминированная, а не вероятностная. Отписки — тоже через `chat_member`.
4. Для схемы «посадочный пост» (переход сразу на пост, подписка потом) — вероятностный матчинг клик↔подписка
   по временному окну как fallback, с честным confidence score.

## Фазы

### Фаза 0 — Скелет и инфраструктура ✅ (эта сессия)
- [x] Монорепа npm workspaces: `apps/web`, `apps/bot`, `packages/db`
- [x] Prisma schema ядра (users, workspaces, channels, links, clicks, subscribers, events)
- [x] Скелет бота (grammY + Fastify: webhook, редирект `/l/:slug`, health)
- [x] Скелет Next.js (лендинг + заглушка кабинета)
- [x] Документация деплоя на Railway

### Фаза 1 — Ядро атрибуции (MVP бота)
- Онбординг: `/start` → добавить бота админом в канал → канал появляется в системе
- Конструктор ссылок в боте и в кабинете: метка креатива, UTM, посадочный пост
- Редирект-сервис с записью кликов (Redis-кэш slug→invite, чтобы редирект был <50ms)
- Обработка `chat_member`: joins/leaves, привязка к ссылке, Premium-флаг
- Ежедневный отчёт в бота (кто пришёл/ушёл, топ источников) — паритет с tgtrack free
- Список подписчиков с источником и датами

### Фаза 2 — Личный кабинет
- Auth через Telegram Login Widget (без паролей — это наша аудитория)
- Дашборд канала: прирост/отток, график по дням, разбивка по источникам, % отписок по источнику
- Когорты отписок (1–7 / 7–30 / 30+ дней) и когорты new/old аудитории
- Таблица ссылок: клики → подписки → конверсия → отписки, сортировки/фильтры
- Экспорт CSV/Excel (паритет), публичная share-ссылка отчёта (дифференциатор)
- Воркспейсы и приглашение команды (роли: owner / admin / viewer)

### Фаза 3 — Маркетинговый сайт (параллельно с Фазой 2)
- Направление: **data-driven dark luxury** — тёмная тема, стеклянные поверхности,
  «живой» анимированный дашборд в хиро (fake-realtime данные), scrollytelling блоков «как это работает»
- Секции: hero с анимированным графиком → боль (Excel/слепой закуп) → как работает (3 шага) →
  сравнение схем закупа (интерактив, как у tgtrack, но лучше) → фичи → тарифы → FAQ → CTA
- Соцдоказательства, калькулятор окупаемости (интерактивный: CPA до/после)
- SEO: русские ключи «откуда подписчики телеграм», «стоимость подписчика», блог позже

### Фаза 4 — Конверсии в рекламные кабинеты (киллер-фича tgtrack — паритет+)
- Оффлайн-конверсии «подписка» в Яндекс.Директ (API Метрики, оплата за подписку)
- Скрипт для лендингов (Tilda/Flexby/свои) + задержка отправки для отсева быстрых отписок
- Пиксель/постбек API для VK Ads и произвольных систем
- Разметка Telegram Ads: массовая генерация ссылок под сотни каналов таргета (как Telescope)

### Фаза 5 — Деньги и агентства (то, за что платят x5)
- Модуль «Продажи» (как Prizma): загрузка списка покупателей/лидов (TgID/username),
  интеграции GetCourse / Tribute / webhook CRM → ROMI по источнику
- Сравнение подрядчиков-закупщиков
- Антифрод: детекция налива ботов, отчёт-пруф для возврата денег за интеграцию
- White-label отчёты для клиентов агентства
- AI-сводки: еженедельный автоотчёт «что масштабировать, что отключить»

### Фаза 6 — Монетизация
- Free: 1 канал, атрибуция + ежедневный отчёт (движок дистрибуции, как у tgtrack)
- Pro (~1 490–1 990 ₽/мес/канал): конверсии в кабинеты, полный дашборд, экспорт
- Agency (от ~8 000 ₽/мес): воркспейсы, подрядчики, white-label, продажи/ROMI
- Оплата: Telegram Stars + ЮKassa (РФ) / карта (позже)
- Партнёрка 20% recurring

## Риски

1. **Bot API повеления** — `chat_member` требует чтобы бот был админом; изменения Telegram могут задеть всех конкурентов одинаково.
2. **Privacy** — храним TgID подписчиков чужих каналов; нужна оферта + политика (как у всех конкурентов).
3. **Redirect uptime** — редирект это точка отказа рекламного трафика; health-check + Railway autoscale, slug-кэш в Redis.
4. Узкий RU-рынок — закладываем i18n с первого дня (ключи, не хардкод).
